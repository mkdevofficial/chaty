## 5. Full Description
**Chaty** is a modern, full-featured instant messaging application designed for fast, seamless, and secure communication. Built with Material 3 design and offline-first capabilities, Chaty provides an intuitive chat experience in both Arabic and English.

### 🌟 Key Features of Chaty:

* 💬 **Real-Time Messaging:** Instant bidirectional communication with WebSocket integration, message delivery status indicators (Sent, Delivered, Read ticks), and real-time typing indicators.
* 🎙️ **Advanced Voice Notes:** Hold-to-record voice notes with slide-to-cancel, waveform preview, and multi-speed playback (1.0x, 1.5x, 2.0x).
* 📸 **Daily Stories:** Share moments through photo stories with captions or colorful text stories, complete with full-screen viewer and viewer lists.
* 📁 **Media & File Sharing:** High-resolution image messages with pinch-to-zoom viewer, alongside seamless document and file transfers.
* 🎭 **Vector Sticker Packs:** 36 high-resolution vector stickers across 3 categories (Emojis, Cute Cats, Gestures) plus a quick-access recent stickers drawer.
* ⚡ **Offline-First Architecture:** Powered by local SQLite caching, Chaty allows you to browse conversations, read past messages, and view cached media even without an active internet connection.
* 🎨 **Deep Customization:**
  * Light, Dark, and System theme modes.
  * 4 dynamic accent colors: Emerald Green, Ocean Blue, Royal Violet, and Amber Gold.
  * Customizable chat background wallpapers (Doodle, Warm gradient, Dots, Default).
* 🔒 **Security & Authentication:** Secure token storage with support for phone/password onboarding and Google Sign-In.
